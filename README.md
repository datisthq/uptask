# Uptask

Run TypeScript functions from the CLI: point uptask at a glob, and every function exported
from a matching file becomes a command, with arguments, options, defaults and `--help`
derived from its signature and JSDoc.

| Channel | Package                                          | Install              |
| ------- | ------------------------------------------------ | -------------------- |
| npm     | [`uptask`](https://www.npmjs.com/package/uptask) | `npm install uptask` |

The docs live at [uptask.dev](https://uptask.dev), built with livemark from `docs/`. This
repository holds the package in `source/`; see [Contributing](CONTRIBUTING.md) for the layout
and the commands.
